Как работает код на Python

Разбор скриптов из обоих отчётов: thread_demo.py (Практика № 2) и sync_sem.py / sync_var2_new.py (Практика № 3) + пошаговый симулятор.

Практика 2

1. Скрипт thread_demo.py — создание потока в системе

import threading import time import os def worker(): print(f"Поток запущен! ID потока (Native ID): {threading.get_native_id()}") time.sleep(20) print("Поток завершил работу.") print(f"Главный процесс запущен. PID: {os.getpid()}") t = threading.Thread(target=worker, name="MyWorkerThread") t.start() t.join()
  • os.getpid() — возвращает PID главного процесса Python в ОС (например, 4852).
  • threading.Thread(target=worker, name="MyWorkerThread") — создаёт объект нового потока, который выполнит функцию worker.
  • t.start() — реально запускает поток на уровне ОС.
  • threading.get_native_id() — возвращает системный ID потока (TID), который в Linux отличается от PID главного процесса (например, 4854), но принадлежит тому же процессу.
  • time.sleep(20) — держит поток живым 20 секунд, чтобы его можно было увидеть в системе.
  • t.join() — заставляет главный процесс дождаться завершения дочернего потока, прежде чем выйти.
Практика 3

2. Класс PointSemaphore (Вариант 1 и Вариант 2)

class PointSemaphore: def __init__(self, target_count): self.sem = threading.Semaphore(1) # 1. Бинарный семафор (критическая секция) self.count = 0 # 2. Счётчик потоков, прошедших точку self.target_count = target_count # 3. Сколько потоков нужно для открытия точки self.all_done = threading.Event() # 4. Событие-барьер для следующих потоков def pass_point(self, name): print(f"Поток '{name}' начался и ожидает семафор.") time.sleep(random.uniform(0.2, 0.8)) self.sem.acquire() # Захват семафора (входит только 1 поток) print(f"Поток '{name}' захватывает семафор.") print(f"Поток '{name}' в семафоре.") current_val = self.count self.count += 1 print(f"Переменная семафора равна: {current_val}. Поток '{name}' выходит из семафора.") if self.count == self.target_count: # Если пришли ВСЕ нужные потоки — self.all_done.set() # открываем барьер для следующих потоков! self.sem.release() # Освобождение семафора

Как работают функции потоков:

  • run_A() — сразу вызывает point1.pass_point("A"). После него point1.all_done.set() открывает Точку 1.
  • run_after_p1(name, target_point) — вызывает point1.all_done.wait() (ждёт завершения Точки 1), затем поток идёт в свою целевую точку (point2, point3 или point4).
  • run_after_p2(name) — ждёт point2.all_done.wait(), затем проходит point3 (потоки D, E, F).
  • run_after_p3(name) — ждёт point3.all_done.wait(), затем проходит point4 (потоки G, H).
  • run_K() — ждёт point4.all_done.wait() и завершает программу (The End).
